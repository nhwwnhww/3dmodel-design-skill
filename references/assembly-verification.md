# Assembly verification
多零件或行为相关作品启用。本阶段数字检查与 physical gate 分开记录，不能互相替代。

1. 为每件指定稳定 ID、装配坐标系、导出/装配 transform；核对 handedness、缩放和单位。
2. 指定每对 mating surfaces、允许接触区域和设计间隙；预期接触不可用整对零件豁免来隐藏其他区域穿透。
3. 先用包围盒 broad phase 排查；AABB overlap 仅是可能相交，需 CAD 实体布尔/可靠网格工具或截面确认。disjoint 也不证明可装配或满足目标间隙。
4. 从分离状态检查插入路径、工具/手指空间、装配顺序、拆卸与防脱。必要时记录分步姿态。
5. 活动件覆盖行程端点及中途风险姿态；离散采样可能漏掉碰撞，不能将有限采样称为连续证明。
6. 将数值结果与 exploded view、装配状态、截面对应，记录未解决项，再进入实际装配测试。

`scripts/assembly_check.py` 只接受已在同一毫米坐标系中的 AABB，输出筛查分类。它没有碰撞引擎、最小间隙、姿态变换、装配路径或 motion sweep 实现。

单体无装配且无行为时，在 spec 写明 N/A 理由；若宣传“卡得住/可旋转/耐重复拆装”则不能以外观摆件为由跳过实际测试。
