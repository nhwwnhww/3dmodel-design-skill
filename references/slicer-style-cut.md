# Plane cut、分件与纯打印连接
先区分为了观察的 section（不改变输出）和真正 splitting geometry（改变构建源）。不要把 shader clipping 截图导出为最终实体。

分件原因：超出当前可用打印区域、减少难移除支撑、改善可见面或层方向、可更换局部件。对比整体打印与分件后的接缝、强度、装配和丢件成本。

优先回到 source of truth 定义切面坐标、法向、保留侧和件名。纯打印连接可选定位销、插槽、燕尾、卡扣；不要默认加金属紧固件或磁铁。连接尺寸依项目 coupon 决定。

检查：切后实体封闭、各件最薄处、连接根部、打印朝向、插入顺序、防装反、配合可达性。自动生成定位销不证明实际可拼回。

若在 Bambu Studio GUI 使用 cut 功能，保存原模型和操作后的 3MF、切面/连接参数与截图，并在 spec 明确该项目为后续制造处理源；重要配合修改优先回写 CAD。更改源几何后不可沿用旧切片切面结果。
