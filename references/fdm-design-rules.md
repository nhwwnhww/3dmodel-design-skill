# Printer/material-aware DfAM QA
规则按三层管理：几何事实（单位/封闭性/干涉）、特定设备 profile、特定材料批次实测。经验阈值必须带出处和适用机器、喷嘴、线宽、层高、朝向；任何一层缺失都不能强推固定间隙或通用悬垂角。

| 检查 | 输入/判断 | 验证证据 |
|---|---|---|
| 可放置性 | 当前 Bambu profile 的可用区域、裙边/支撑和排布 | 切片板预览，不能仅比较名义打印体积 |
| 薄壁/小细节 | 实际 extrusion width、wall generator、局部壁厚 | 截面 + 逐层挤出路径是否保留 |
| 朝向/强度 | 载荷、层间方向、外观面、底部接触 | 朝向对比及局部实测 |
| 悬垂/桥接 | 跨距、材料、冷却、速度与支撑策略 | 同条件样条与切片预览 |
| 支撑 | 能否接触并移除，不损坏外观与卡扣 | 支撑路径检查和实物拆除 |
| 翘曲/稳定性 | 大平面、细高特征、尖角、接触面 | 首层/中途稳定性实测 |
| 空腔 | 封闭空间、排出碎屑、内部支撑残留 | 关键截面与路径审阅 |

方向选择不能只最小化支撑体积：同时考虑可见面、触感、层间载荷和装配界面。至少记录选择理由与被放弃方案的主要缺点。

wallcheck.py 尚不实现壁厚测量；手动 CAD 截面测量注明位置和方法。网格 watertight 不会检测所有自交，也不能证明每层具有可打印路径。
