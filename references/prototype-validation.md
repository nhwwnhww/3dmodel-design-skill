# Physical prototype → feedback → revision
分层实测：风险 coupon → 功能局部 → 整件原型。coupon 只能证明对应局部，不可替整件盖章。

每次 trial 记录：revision、源/几何/profile hash、日期、打印机/喷嘴/板材、具体材料及状态、朝向、支撑/后处理、打印是否完成、缺陷位置、测量方法和测量值、照片、操作者与原始反馈。

开测前定义 acceptance criteria。装饰品关注落地稳定、可见面、细节还原；配合件关注装配力、间隙/晃动、拆装损伤；机构关注全行程、卡滞、保持和与用途对应的循环/载荷。不编造跨材料寿命或可靠性结论。

将用户报告标为 user-reported；区分直接观察、仪器测量、主观体验。照片不证明不可见的力学行为。把未测项保留为 unknown。

失败记录结构：现象 → 候选原因 → 最小可区分试验 → 修改 → 复测。能隔离变量时一次改一项；记录失败版本，不用成功照片覆盖失败证据。
几何修改后重新 build/visual/geometry/DfAM/slice；工艺修改后重做受影响工艺与功能测试。v0.1 不继承旧 physical passed：任何几何、材料或打印配置变化后，旧记录仅作历史参考，当前版本必须重新完成整件原型及所宣称行为的实测。纯文案变更不改变这些输入，仍须核对描述与证据一致。

没有打印机可继续完成数字阶段，交付试印包和待填实验表，不能虚构 print-tested。MakerWorld release candidate 按此 Skill 要求含当前整件原型与用户反馈记录。
